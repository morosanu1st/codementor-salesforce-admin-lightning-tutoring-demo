# Salesforce Learning Path — Study Map (Sample)

A practical sequence for Admin + Lightning overview. Adjust pace to your schedule.  
**Reminder:** use this for learning — complete your own assessed coursework.

---

## Week 1–2 · Org & data model
- [ ] Create / open a Developer Edition org  
- [ ] Navigate Setup; find Object Manager  
- [ ] Create a custom object with 3–5 fields (text, number, date, picklist)  
- [ ] Add a lookup and a master-detail relationship (know when each fits)  
- [ ] Practice task: model a simple “Library → Book → Loan” mini schema  

## Week 3 · Lightning pages & navigation
- [ ] Customize a Lightning record page in App Builder  
- [ ] Add related lists, highlights panel, and a simple Dynamic Form if available  
- [ ] Create a custom Lightning app with useful nav items  
- [ ] Practice task: before/after screenshot notes of a cleaned-up record page  

## Week 4 · Security basics
- [ ] Explain OWD (Private / Public Read Only / Public Read/Write) in your own words  
- [ ] Contrast profile vs permission set  
- [ ] Build a permission set for “extra” object access without cloning profiles  
- [ ] Practice task: diagram who can see which records in a 3-role toy org  

## Week 5 · Automation (Flow-first)
- [ ] Build a before-save (fast field update) Flow  
- [ ] Build a simple screen Flow for guided data entry  
- [ ] Add a validation rule and explain why Flow isn’t always the right tool  
- [ ] Practice task: “when Status = Closed, require Closed Reason” (validation or Flow — justify choice)  

## Week 6 · Reports & dashboards
- [ ] Tabular + summary reports; chart on a dashboard component  
- [ ] Folder sharing basics  
- [ ] Practice task: pipeline-style summary by Status (even on custom objects)  

## Week 7 · SOQL fundamentals
- [ ] Write SELECT / FROM / WHERE queries in the Query Editor  
- [ ] Parent-to-child and child-to-parent relationship queries (intro)  
- [ ] Respect governor-limit mindset (don’t query in loops — conceptual)  
- [ ] Use `soql-cheatsheet.md` as a desk reference  

## Week 8 · Lightning components overview (Admin lens)
- [ ] Know Aura vs LWC at a high level  
- [ ] Place an existing component on a Lightning page  
- [ ] Clarify Admin vs Dev ownership (declarative vs code)  
- [ ] Optional stretch: read a simple LWC HTML/JS pair without writing production code yet  

---

## Session prep checklist
- Dev org login ready  
- 1 concrete question from Trailhead or class notes  
- Willingness to share screen and click Setup yourself
