## Ethics first (important)

I **teach** Salesforce concepts, help you reason through Trailhead modules, and coach study plans.

I will **not**:
- Complete your homework, quizzes, or exams for you  
- Log into your school / employer org to finish graded work  
- Share answer keys meant for assessed submissions  

If you’re stuck on an assignment, we review the **underlying skill** (objects, security, SOQL, etc.) so you can finish it yourself.

## Learning path (Trailhead-style)

| Phase | Focus | Typical Trailhead-style modules |
|-------|--------|----------------------------------|
| 0. Setup | Developer Edition org, Navigator, Setup menu | Org orientation, personal settings |
| 1. Data model | Objects, fields, relationships, record types | Data Modeling, Schema Builder basics |
| 2. UI & UX | Page layouts, Lightning App Builder, compact layouts | Lightning Experience customization |
| 3. Security | Profiles, permission sets, OWD, sharing | User Management, Data Security |
| 4. Automation | Validation rules, Flow basics (prefer Flow over legacy Process Builder) | Flow Builder fundamentals |
| 5. Reporting | Reports, dashboards, folders | Reports & Dashboards |
| 6. SOQL intro | SELECT, WHERE, relationships, limits mindset | Write SOQL Queries (concepts) |
| 7. Lightning overview | Aura vs LWC at a high level; when Admins vs Devs own what | Lightning components overview |

### Admin vs Developer track
- **Admin track:** declarative tools — objects, security, Flow, reports, Lightning pages  
- **Dev track:** Apex, LWC, packaging, CI — we only **overview** this unless you explicitly want to go deeper  

Most mentees start Admin-heavy, then add Lightning / SOQL as needed.

See `learning-path.md` for a week-by-week study map and `soql-cheatsheet.md` for a tiny query reference.

## How 1:1 sessions work
1. Clarify your goal (Admin cert prep, job skills, class support — conceptual only)  
2. Confirm you have a **Developer Edition** (or sandbox you may use for learning)  
3. Live Build-along in Setup / Flow / App Builder while you drive  
4. Short knowledge checks (I ask; you explain — no graded-exam shortcuts)  
5. Homework: Trailhead modules + 1 hands-on org task before next time
